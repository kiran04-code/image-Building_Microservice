# Image Building Microservice

A TypeScript-based microservice for building and managing container images.

## Overview

This microservice provides functionality for building, managing, and deploying container images as part of a cloud computing platform. Built with TypeScript, it offers type-safe operations and robust error handling.

## Tech Stack

- **Language**: TypeScript (98.8%)
- **Frontend**: HTML (1.2%)
- **Architecture**: Microservice

## Features

- Container image building capabilities
- Image management and versioning
- Integration with cloud computing infrastructure

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/Cloud-Computing-CP-1/image-Building_Microservice.git
cd image-Building_Microservice
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
